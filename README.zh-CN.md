# Chat Archify Lite

[English](README.md) | **简体中文**

把长对话整理成可点击的脉络图：先看分支与决定，再点节点查看来源、Markdown 文档和文件下载。普通对话也可以使用，不要求代码仓库。**只有明确调用时才生成。**

## 本版功能

一个对话、一张总览；最多 3 个不同的非对话内嵌文件；搜索仅匹配节点标题。

两版都保留完整节点和关系、无交叉布局检查、节点证据、Markdown 排版与原文、文件下载、离线 HTML 和结构化 JSON。免费额度不会截断对话脉络。

超额资源保留名称、原始引用、节点关联及限制说明，不嵌入正文。对话原文不占附件额度；兼作产物的文件计入额度。重复路径不重复计数，缺失或被排除的文件不占成功嵌入名额。Lite 无增量更新入口，可重新生成当前图。

## 安装与调用

解压 ZIP，将其中整个 `chat-archify-lite` 文件夹复制到宿主 skills 目录，例如 `~/.codex/skills/`。保留 `assets/`、`scripts/`、`references/`、`tests/` 和 `agents/`。入口为 `~/.codex/skills/chat-archify-lite/SKILL.md`。

```text
使用 $chat-archify-lite 梳理我指定的对话，保留分支、决定、转向与来源证据，并附相关资源。
```

`agents/openai.yaml` 已设置 `allow_implicit_invocation: false`。其他宿主可能不识别此设置；以宿主安装规则为准。无法访问的历史须由用户提供导出，不能根据摘要补写原话。

## 运行示例

生成需要 Python 3.9+、Node.js 18+ 和另行安装的 [Archify](https://github.com/tt-a1i/archify)。当前集成验证版本为 2.17.0-dev.1；Archify 不随本包分发或自动安装。打开已生成页面只需支持 JavaScript、SVG 和 Blob 的浏览器。

在本 Skill 目录运行（路径含空格时保留引号）：

```sh
python scripts/build_lite_demo.py --archify-dir "<包含 bin/archify.mjs 的目录>" --out-dir "demo-output"
```

打开 `demo-output/chat-archify-lite-demo.html`。示例包含一份虚构对话、5 个节点、5 条关系和 4 个 Markdown 资源，不含真实用户资料。点击“合并为弹性阅读计划”查看“补充阅读资料”，或搜索附件正文专用词“蓝鲸书签”：Lite 显示额度说明且不检索正文，Pro 可以阅读与搜索。

脚本执行 Archify showcase、全部连线几何/拓扑、文件字节及 Node fake-DOM 回归。fake-DOM 不是浏览器或视觉验收；实际浏览器仍需单独验证。脚本不会联网、安装依赖或启动服务。

## 文件与边界

- [SKILL.md](SKILL.md)：AI 执行步骤；[记录格式](references/graph-format.md)：可迁移的事实记录。
- 每个文件仍受 25 MiB 上限与凭据排除规则限制。“完整附件”不代表忽略这些规则。
- 页面包含被内嵌的对话/附件原文，分享 HTML 也会分享这些内容；Blob 链接只在当前页面会话中有效。
- Markdown 使用随包 [Marked MIT 许可](assets/vendor/marked-LICENSE.md)，通过受控 DOM 排版，不执行原文 HTML 或自动加载远程图片。
- 说明文档中英双语；当前查看器和示例主要为中文。
- 本包不包含支付、在线授权、更新通知或自动更新服务，也不会自动发布用户内容。
